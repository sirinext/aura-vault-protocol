# Video 1: How to Deposit into Aura Vault

**Runtime:** 3:30  
**Audience:** First-time Aura Vault users  
**Recording network:** Stellar testnet only  
**Status:** Production draft; marketing and product review pending

## Before recording

- Use a clean browser profile with Freighter installed and set to Stellar testnet.
- Prepare a funded testnet wallet, test tokens, and the current testnet vault URL and contract ID.
- Confirm the app is connected to testnet and that the displayed share preview matches the contract's current exchange rate. Use a small demonstration amount.
- Never show a recovery phrase, private key, personal wallet, or real funds. Blur account identifiers in the recording.
- Record at 1920×1080. Keep the pointer deliberate and pause after important UI changes so captions can be timed.

## Script and shot list

### Scene 1 — Hook (00:00–00:15)

**Screen cue:** [SCREEN RECORDING START] Open on the vault dashboard. Highlight the share price, then the deposit panel.

**Presenter:** “A yield vault lets you deposit tokens and receive shares that represent your part of the pool. When yield is harvested, the value of each share can rise automatically, so you do not need to withdraw and deposit again to compound.”

**Speaker note:** Keep this factual: yield and share value can change and are not guaranteed.

### Scene 2 — Prerequisites (00:15–00:30)

**Screen cue:** [CUT TO] Show a checklist: Freighter, testnet selected, test XLM for fees, supported test token.

**Presenter:** “You’ll need Freighter, a wallet set to Stellar testnet, a little test XLM for network fees, and the test token accepted by this vault. This walkthrough uses testnet tokens only.”

**Speaker note:** Do not show wallet setup or expose credentials. If using Friendbot, show only the public testnet flow.

### Scene 3 — Open the app (00:30–01:00)

**Screen cue:** [SCREEN RECORDING] Navigate to the verified testnet app URL. Pause on the testnet badge and vault identity.

**Presenter:** “Open the official Aura Vault testnet app. Check the testnet label and confirm the vault and token before you connect. This is a test environment; do not send mainnet assets here.”

**Speaker note:** Insert the verified URL and contract ID in the published description after product review.

### Scene 4 — Connect Freighter (01:00–01:30)

**Screen cue:** [CLICK] Select Connect Wallet, choose Freighter, then show the wallet approval prompt with sensitive details obscured.

**Presenter:** “Select Connect Wallet, choose Freighter, and review the connection request in the wallet. Approve it only if the app and network are the ones you expect. Your connected public address should now appear in the app.”

**Speaker note:** Show approval, not a seed phrase or private key. Keep the testnet badge visible after connection.

### Scene 5 — Enter amount and review preview (01:30–02:00)

**Screen cue:** [ZOOM] Click the deposit amount field. Enter a small test amount. Hold on the share preview and any validation or fee information.

**Presenter:** “Enter the amount you want to deposit. Review the estimated shares, share price, and any fee information shown. The preview is an estimate based on the current vault state; the final result is determined when the transaction executes. Make sure the amount and token are correct before continuing.”

**Speaker note:** Use a demo value that has been checked against the live testnet app. Do not narrate a fixed share amount unless it matches the recorded preview.

### Scene 6 — Confirm and sign (02:00–02:30)

**Screen cue:** [CLICK] Select Deposit. Show the Freighter transaction review and confirmation state; blur account details and transaction identifiers.

**Presenter:** “Choose Deposit. In Freighter, review the transaction details, including the network, contract, function, and amount. If anything differs from what you expect, reject the request. Otherwise, sign it and wait for the app to confirm the transaction.”

**Speaker note:** Never imply that a transaction is confirmed before the app or network reports success.

### Scene 7 — Verify shares (02:30–03:00)

**Screen cue:** [WAIT FOR CONFIRMATION] Return to the dashboard and highlight the updated share balance and underlying asset estimate.

**Presenter:** “The transaction is confirmed. Your share balance is now visible on the dashboard. Shares track your proportional ownership of the vault; the estimated underlying value can change as the vault’s assets and share price change.”

**Speaker note:** Show the actual confirmed testnet result. Avoid exposing the full wallet address.

### Scene 8 — Outro (03:00–03:30)

**Screen cue:** [END CARD] Show the official documentation and the next tutorial title: How to Withdraw from Aura Vault.

**Presenter:** “That’s how to make a testnet deposit into Aura Vault. Before using any production app, verify its official address, network, token, and contract details. Next, watch our guide to withdrawing shares. Find the links in the description.”

**Speaker note:** Add only verified official links after product review.
